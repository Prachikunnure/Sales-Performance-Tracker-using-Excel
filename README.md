
# Sales Performance Dashboard | Advanced Excel

## Project Overview
This project is an interactive Sales Performance Dashboard created using Microsoft Excel. It provides insights into sales executives' performance by analyzing total sales, target achievement, and performance gaps through dynamic charts and KPI metrics.

The dashboard helps businesses monitor employee performance and identify top and low performers efficiently.
## Features

- Interactive Sales Dashboard
- Total Sales Analysis
- Target Achievement Percentage
- Away From Target Percentage
- Top Performing Sales Executives
- Lowest Performing Sales Executives
- Dynamic Charts & Visualizations
- Clean and Easy-to-Understand Dashboard

## Dataset Information

The dataset contains sales performance details including:
